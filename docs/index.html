产品介绍

不用截图，也不用一张张右键另存

商品图分散在主图区、轮播缩略图和详情描述里，还常常是懒加载的。电商图片助手会把整页扫一遍，滚动触发加载，再把图片整理进画廊，你只负责挑选。

以前的做法

  • 滚动截图，画质被压缩
  • 逐张右键另存，文件名混乱
  • 详情图懒加载，容易漏图
  • JPG、WebP、PNG 混在一起

  • 一次扫描当前页面的全部图片
  • 自动滚动，触发懒加载图片
  • 画廊勾选，所见即所得
  • 统一 PNG，按平台和商品归档

核心功能

从抓到存，每一步都为省时间设计

不是简单地收集页面上的图片链接，而是把「找图、筛图、转格式、存文件」一次性做完。

一键采集

详情页右下角常驻「获取图片」按钮，点击即扫描当前页面，不需要打开开发者工具。

懒加载不漏图

自动分段滚动页面触发图片请求，还没进入视口的详情长图，也能完整收集进来。

原图还原

清理 CDN 链接里的尺寸与质量后缀，淘宝、京东、拼多多分别按各自规则取回高清原图。

画廊挑选

新标签页展示全部图片，支持逐张勾选、全选、反选、清空，以及键盘快捷键操作。

真正的 PNG

下载前逐张解码重绘，JPG、WebP、AVIF 都会转换成真正的 PNG 文件，而不是只改后缀。

批量与重试

3 张并发下载并显示进度，可随时取消；失败的图片单独标记，可以一键重试。

使用流程

三步，从商品页到图片文件夹

  1. 01

    打开商品详情页

    支持淘宝 / 天猫商品详情页、京东商品页，以及拼多多商家后台的商品页面。

  2. 02

    点击「获取图片」

    右下角按钮显示采集进度，完成后自动在新标签页打开图片画廊。

  3. 03

    挑选并下载 PNG

    勾选需要的图片，统一转换并保存到「电商图片 / 平台 / 商品标题 /」文件夹。

安装步骤

一分钟装好，刷新页面就能用

扩展以「已解压」的方式加载，不需要上架商店。首次安装完成后，回到商品详情页刷新一次即可。

需要桌面版 Chrome 110 及以上
  1. 1

    准备扩展文件夹

    确认项目文件夹中包含 manifest.json，不需要安装依赖或执行构建。

  2. 2

    打开扩展管理页

    在地址栏输入下面的地址，或从菜单进入「扩展程序 → 管理扩展程序」。

    chrome://extensions
  3. 3

    开启开发者模式

    打开扩展管理页右上角的「开发者模式」开关，页面会出现「加载已解压的扩展程序」。

  4. 4

    加载并固定扩展

    点击「加载已解压的扩展程序」，选择包含 manifest.json 的文件夹；在工具栏固定图标后，打开商品详情页就能使用。

常见问题

安装前想确认的几件事

如果这里没有覆盖你的问题，可以先在商品页实际点一次「获取图片」，大多数情况都会在画廊里得到反馈。

为什么有些图片没有被抓取到？

页面可能还没有加载完，或者图片位于需要登录、滑块验证后才显示的区域。先手动滚动一遍详情页，再重新点击「获取图片」。单次采集上限为 500 张，超出部分会被截断。

下载失败怎么办？

少数 CDN 会校验来源或签名。失败项会在画廊里标红，可以点击「重试失败项」；仍然失败时，可通过卡片上的「打开原图」手动保存该张图片。

图片会被上传到服务器吗？

不会。采集、转换和下载都在你的浏览器里完成，扩展没有自有服务器，也不会上传、留存任何图片。

手机上的 Chrome 可以用吗？

目前面向桌面版 Chrome 开发。拼多多的移动端商品页可以在桌面 Chrome 中打开后使用，手机浏览器暂不支持安装扩展。

支持哪些商品页面？

淘宝 / 天猫商品详情页、京东商品页、拼多多商品页与拼多多商家后台的商品相关页面。其他电商站点暂未适配。
